# grey-forecasting

## Trigger

- 事件：`ALGO_GREY_FORECAST`。
- 当样本较短、系统趋势较平滑、信息不完全且需要可解释低成本预测时，由 `model-selection` 作为候选路由。

## Scope

覆盖 GM(1,1) 等灰色预测思想及必要改进。灰色模型不是“小样本万能法”，趋势突变、强季节、强外生驱动时应优先考虑其他模型。

## Inputs

- 按时间排序的正值或可合理变换序列
- 预测步长
- 数据量与时间间隔
- 是否存在明显季节/结构突变/外生变量
- 可比较的 naive baseline

## Procedure

1. 检查序列定义、单位、时间间隔和缺失处理；任何平移/变换必须记录并可逆。
2. 先建立 naive 或线性趋势 Baseline，避免灰色模型“无对照”。
3. 检查原序列是否满足灰色一阶累加建模的基本趋势要求；级比或其他适用性检查只作为诊断，不把经验阈值当官方定理。
4. 建立 AGO 序列、背景值和白化方程，明确参数估计方法与还原公式。
5. 通过滚动/留后验证评估真实外推能力，不用训练内拟合误差代替预测性能。
6. 若残差有系统结构，先诊断原因，再考虑残差修正、代谢/滚动 GM、Verhulst 或带外生项的扩展，而不是盲目叠加。
7. 对预测区间和长期外推保持保守：随着 horizon 增大，报告不确定性和模型边界。

## Decision Rules

- 强季节/周期：优先 `ALGO_TIME_SERIES`。
- 明显外生驱动且样本足够：考虑监督学习/回归。
- 单调饱和趋势可评估 Verhulst 类结构，但必须验证。
- 若灰色模型不优于 naive baseline，不因“方法特色”强行保留。

## Validation Design

- 留后/滚动预测误差
- 与 naive、线性趋势或简单指数平滑比较
- 参数和起点敏感性
- 长短 horizon 分层误差
- 残差是否仍存在结构性趋势

## Outputs

- 适用性诊断
- Baseline 与灰色模型定义
- 参数、预测值与误差
- 滚动验证结果
- 失效边界与是否保留建议

## Checks

- 时间顺序未泄漏
- 训练内拟合不冒充预测验证
- 变换可逆且单位一致
- 与简单 Baseline 公平比较
- 长期外推未过度宣称

## Failure

- 强周期或长期依赖：转 `ALGO_TIME_SERIES`
- 需要多个解释变量：转 `ALGO_SUPERVISED_LEARNING`
- 预测高度不稳定：转 `RESULT_UNSTABLE`

## Common Failure Modes

- **样本少但并不平滑**：样本少本身不是使用灰色模型的理由；如果序列被季节、政策跳变或周期主导，GM 的指数趋势结构会产生系统偏差。
- **为了通过级比检验反复平移数据**：任何平移都会改变解释，必须说明为什么可接受，并在预测后正确逆变换。
- **把后验差比/小误差概率当预测能力**：这些更多反映拟合残差结构，不能替代 out-of-sample 检验。
- **长 horizon 外推过度**：GM(1,1) 的指数结构可能快速放大，超过数据支持范围时只做情景参考。

## Reproducibility Notes

记录原始序列版本、时间排序、平移/变换、背景值构造、参数估计公式、训练窗口、验证窗口和最终预测 horizon。滚动 GM 每次更新窗口时要记录窗口边界，避免结果不可追溯。

## Handoff

模型选定后转 `MODEL_CONTRACT_MISSING`；需要比较多个预测模型时转 `MODELS_NEED_COMPARISON`。
