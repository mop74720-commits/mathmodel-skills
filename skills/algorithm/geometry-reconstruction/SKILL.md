# geometry-reconstruction

## Trigger

- 事件：`ALGO_GEOMETRY`。
- 通常由 `model-selection` 在识别问题结构后路由；用户直接点名该算法族时也可调用。
- 本 Skill 只决定该算法族内的技术路线，不决定比赛阶段、时间预算、是否冻结或提交。

## Scope

当核心信息来自形状、边界、位置、姿态、距离或空间约束时使用。强调实体几何而非把所有对象简化为点。

## Inputs

- 坐标系、单位、维度与几何实体定义
- 边界/尺寸/姿态/可见性条件
- 测量点、图像或点云来源
- 目标：重建/覆盖/碰撞/最短几何量
- 数值容差和误差来源

## Procedure

1. 首先冻结坐标系、原点、轴方向、角度单位和变换顺序；所有旋转/投影公式必须与代码 convention 一致。
2. 判断对象可否近似为点、线、圆/矩形/多边形或有限体。若碰撞/遮挡取决于边界，禁止只用中心点距离。
3. 利用周期性、对称性、刚体变换等结构压缩搜索空间，并写出为什么不会漏解。
4. 选择几何算法：解析几何、最近距离、分离轴、点到边界、distance transform、优化式重建等；优先保留可校验的简单几何 Baseline。
5. 处理图像/点云时明确像素到物理坐标转换、分辨率、阈值和噪声，必要时做亚像素/插值误差分析。
6. 对边界情况做专门测试：相切、共线、角度跨越、周期边界、浮点容差。
7. 结果用解析特例、对称性、已知几何量或独立算法交叉验证，不仅依赖可视化看起来正确。

## Decision Rules

- 坐标变换的 active/passive convention、旋转顺序和右手系必须一次冻结；这类错误常能产生“看起来合理”的图。
- 碰撞/遮挡问题优先建实体边界关系，不用中心距离替代，除非已证明等价。
- 利用对称性缩域时要给出群/周期或几何等价理由；经验上“只算一半”不算证明。
- 点云/图像重建中，阈值、分割和坐标标定通常与几何算法同等重要，应纳入敏感性。

## Validation Design

1. 构造轴对齐、零旋转、相切、完全分离等解析边界案例。
2. 正反变换组合应近似恢复原坐标。
3. 对空间搜索算法用小规模暴力枚举验证不漏解。
4. 对像素/点云分辨率加密或阈值变化检查目标几何量稳定性。
5. 图形只用于辅助诊断；最终碰撞/距离/面积等结论必须由数值判据给出。

## Outputs

- 坐标/变换合同
- 几何实体与边界定义
- 搜索空间缩减依据
- 几何求解算法与容差
- 边界案例和独立验证结果

## Checks

- 角度单位和旋转顺序一致
- 有限尺寸实体未被错误点化
- 周期/对称压缩有完备性说明
- 浮点容差不会改变相切/碰撞判定
- 图像像素与物理单位转换明确

## Failure

- 核心是网络连通而非空间边界：转 `ALGO_NETWORK_ROUTING`
- 重建需解非线性参数优化：联动 `ALGO_NONLINEAR_OPT`
- 结果对分辨率/容差敏感：转 `NUMERICAL_SUSPECT`

## Handoff

建模冻结后转 `MODEL_CONTRACT_MISSING`；实现结果可接 `NUMERICAL_SUSPECT`。

统一回执：`status / inputs_used / outputs_written / key_findings / risks / qa_status / handoff`。算法 Skill 可以建议下一事件，但不能替 Coach 做阶段或资源决策。
