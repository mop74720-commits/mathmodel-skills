# cellular-automata

## Trigger

- 事件：`ALGO_CELLULAR_AUTOMATA`。
- 当空间格点、局部邻域规则、扩散/传播/拥挤/土地利用等微观交互是问题核心时调用。

## Scope

覆盖确定性或随机元胞自动机。若连续空间 PDE 已足够表达机制，优先选择更可解释的 PDE；CA 的价值在离散局部规则与涌现。

## Inputs

- 网格/空间离散定义
- 元胞状态集合
- 邻域定义
- 更新规则与同步/异步机制
- 初始与边界条件
- 观测/评价指标

## Procedure

1. 明确为什么空间必须离散为元胞，以及网格尺度对应的现实含义。
2. 定义状态、邻域和更新规则，每条规则都应对应机制或题面事实。
3. 选择同步或异步更新并说明影响；避免更新顺序成为隐含随机源。
4. 明确边界：周期、反射、开放或固定边界会显著改变传播结果。
5. 先做最小格点/极端初态测试，检查规则是否产生明显不合理行为。
6. 对网格尺度、初态、随机种子和关键阈值做稳定性分析。
7. 若有宏观数据，比较涌现的速度、密度、占比、传播前沿等统计量，而不是只展示动画。

## Decision Rules

- 连续扩散/传热等机制明确：优先 `ALGO_PDE_DYNAMICS`。
- 无空间局部交互：不要为“可视化好看”使用 CA。
- 规则依赖个体属性而非格点：考虑 agent-based 模型，但需要单独模型合同。

## Validation Design

- 规则级单元测试
- 网格尺度敏感性
- 初始条件/边界条件敏感性
- 多 seed 重复与区间
- 与宏观观测或解析特例比较

## Outputs

- 元胞状态/邻域/更新合同
- 初边值与随机机制
- 核心宏观指标
- 稳定性与验证结果
- 机制解释与适用边界

## Checks

- 网格尺度有现实解释
- 更新顺序明确
- 边界条件不是默认遗漏
- 随机结果有重复验证
- 结果不只依赖单张演化图

## Failure

- 连续模型更自然且更可验证：转 `ALGO_PDE_DYNAMICS`
- 参数/规则来源薄弱：转 `ASSUMPTION_WEAK`
- 结果高度依赖 seed：转 `RESULT_UNSTABLE`

## Common Failure Modes

- **格点尺度任意**：网格过粗会吞掉局部结构，过细会让参数含义改变并增加计算量；尺度应与现实空间或数据分辨率匹配。
- **同步/异步更新未说明**：同一规则在两种更新机制下可能产生完全不同的宏观行为。
- **边界条件偷懒**：周期边界、封闭边界和开放边界对应不同现实系统，不能只用编码方便性选择。
- **单次漂亮动画冒充验证**：应提取宏观统计量，并做多初态/多 seed/多尺度比较。
- **规则太多导致不可解释**：若每个异常都通过新增规则修补，模型会失去可检验性，应回到机制和数据重新设计。

## Calibration Notes

若参数通过数据校准，明确目标统计量（速度、密度、传播前沿、空间相关等），避免逐像素拟合。校准集与验证集应在时间、空间或情景上合理分离，防止只复现一个初始场景。

## Handoff

完成后转 `MODEL_CONTRACT_MISSING`；实现复杂时转 `IMPLEMENT_MODEL`。
