# statistical-inference

## Trigger

- 事件：`ALGO_STATISTICAL_INFERENCE`。
- 通常由 `model-selection` 在识别问题结构后路由；用户直接点名该算法族时也可调用。
- 本 Skill 只决定该算法族内的技术路线，不决定比赛阶段、时间预算、是否冻结或提交。

## Scope

当目标是判断差异、估计效应或量化统计不确定性，而不是单纯预测时使用。重点是设计、独立性、效应量和多重比较。

## Inputs

- 研究问题/零假设与备择假设
- 样本结构：独立/配对/重复测量/分组
- 变量类型和分布特征
- 样本量与缺失机制
- 需要控制的混杂或多重比较

## Procedure

1. 先把题目问题改写成可检验的参数/效应问题，明确估计对象，不以 p 值代替问题定义。
2. 确认抽样单位和独立性。配对、重复测量、聚类样本不能按独立样本检验处理。
3. 根据变量类型和假设选择参数/非参数方法；正态性检验只是证据之一，样本量和稳健性同样重要。
4. 同时报告效应量和置信区间。显著性不等于实际重要，未显著也不等于“完全无差异”。
5. 多组/多指标检验时考虑 FDR/Bonferroni 等多重比较控制；选择方法需与研究目的匹配。
6. 回归推断检查残差、异方差、共线性和影响点；若目标是因果，必须额外说明识别假设，普通回归不自动获得因果性。
7. 对结论进行稳健性检查，例如替代检验、bootstrap、去除极端点或不同协变量设定。

## Decision Rules

- 检验方法由设计和估计对象决定，不由“数据正态不正态”单一因素决定。
- 大样本下微小差异也可能显著，因此效应量和实际意义必须与 p 值一起解释。
- 多次尝试检验后只报告显著结果属于选择偏差；分析路径和多重比较策略需事先或至少完整记录。
- 观测数据中的组间差异可能来自混杂；没有识别设计时不写成处理效应。

## Validation Design

1. 检查抽样/随机化/配对结构。
2. 计算主效应量及区间，并用 bootstrap 或稳健 SE 做必要复核。
3. 对异常值处理前后结果做透明对照。
4. 多模型/多指标时记录 family 并控制错误发现。
5. 回归模型检查残差与 leverage；结论对模型设定敏感时明确报告。

## Outputs

- 估计对象和假设定义
- 统计方法选择依据
- 效应量/区间/p 值等结果
- 假设诊断与稳健性分析
- 可解释边界：关联/预测/因果

## Checks

- 抽样单位与检验独立性一致
- 报告效应量和区间而非只报 p 值
- 多重比较有控制策略
- 未把相关性写成因果
- 缺失/异常处理不会人为制造显著性

## Failure

- 样本结构复杂：考虑混合效应/层级模型并回到模型选择
- 样本量太小导致结论高度不稳定：转 `RESULT_UNSTABLE`
- 真正目标是预测性能：转 `ALGO_SUPERVISED_LEARNING`

## Handoff

统计结果需论文解释时转 `RESULT_NEEDS_INTERPRETATION`。

统一回执：`status / inputs_used / outputs_written / key_findings / risks / qa_status / handoff`。算法 Skill 可以建议下一事件，但不能替 Coach 做阶段或资源决策。
