# pde-dynamics

## Trigger

- 事件：`ALGO_PDE_DYNAMICS`。
- 通常由 `model-selection` 在识别问题结构后路由；用户直接点名该算法族时也可调用。
- 本 Skill 只决定该算法族内的技术路线，不决定比赛阶段、时间预算、是否冻结或提交。

## Scope

当状态同时依赖时间与空间，边界条件和空间结构决定结果时使用。重点是 PDE 类型、初边值、离散一致性和网格收敛。

## Inputs

- PDE、区域几何与坐标
- 边界条件/初始条件
- 材料/物理参数和单位
- 目标输出与观测位置
- 可用 FEM/FDM/FVM/谱方法环境

## Procedure

1. 识别 PDE 类型和主导物理：椭圆/抛物/双曲或耦合；明确所有边界段的条件类型。
2. 先检查初边值问题是否适定，边界条件数量和物理含义是否充分；不要用数值方法掩盖欠定模型。
3. 按几何和守恒要求选择离散法：规则区域可有限差分，复杂几何常用 FEM，守恒通量问题可考虑 FVM；方法选择需匹配方程结构。
4. 明确空间网格、时间步长、离散阶数和稳定性限制；显式格式检查 CFL 等条件。
5. 做网格加密/步长减半或更系统的收敛研究，比较关键标量和场分布，而非只看图片“差不多”。
6. 检查守恒、边界通量、残差和非物理振荡；必要时与解析解、制造解或简化极限案例对照。
7. 复杂多物理耦合先做单场/退化模型校准，再逐步打开耦合，避免无法定位误差来源。

## Decision Rules

- 边界条件是模型的一部分，不是求解器配置；边界类型选错可能比网格误差严重得多。
- 对流占优、波动或尖锐界面问题，应考虑数值耗散/振荡特性，不默认中心差分或标准低阶单元足够。
- 复杂几何下 FEM 便利不代表自动正确，仍需检查网格质量、单元尺度和边界分区。
- 多物理耦合应先验证每个子系统，再验证耦合能量/通量接口。

## Validation Design

1. 逐步加密网格/时间离散并跟踪关键 QoI，直到变化趋势足以判断收敛或明确暴露未收敛。
2. 有解析特例时优先对照；没有时可用 manufactured solution 或守恒残差。
3. 检查边界通量积分与域内源项/储存变化是否匹配。
4. 观察极值、负值、振荡等非物理现象是否随网格变化。
5. 对耦合模型做关闭耦合/弱耦合极限检查，确认退化模型一致。

## Outputs

- PDE 与初边值合同
- 离散方法和网格/步长选择
- 稳定性与收敛证据
- 守恒/残差/边界检查
- 关键场结果与简化案例对照

## Checks

- 边界条件覆盖完整且物理合理
- 空间/时间离散满足稳定性要求
- 网格加密后关键结论收敛
- 没有非物理负值/振荡而不解释
- 耦合模型有简化/退化验证

## Failure

- 初边值问题欠定：回到 `MODEL_UNCERTAIN`/`ASSUMPTION_WEAK`
- 网格/步长改变结论：转 `NUMERICAL_SUSPECT`
- 空间效应实际可忽略且计算成本过高：考虑降阶到 `ALGO_ODE_DYNAMICS`

## Handoff

数值实现转 `IMPLEMENT_MODEL`，离散可信度转 `NUMERICAL_SUSPECT`。

统一回执：`status / inputs_used / outputs_written / key_findings / risks / qa_status / handoff`。算法 Skill 可以建议下一事件，但不能替 Coach 做阶段或资源决策。
