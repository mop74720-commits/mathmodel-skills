# Network Search & Routing Playbook

## A* 与最短路

- A* 适用于有起点/终点、可计算启发函数的最短路径搜索。
- 若需要保证最优，启发函数必须满足相应可采纳/一致性条件；`h=0` 退化为 Dijkstra。
- 网格搜索需定义邻域、对角移动代价、障碍和坐标尺度，不能把像素距离直接当物理距离。

## TSP

- 小规模可用枚举/动态规划作为精确基准；规模增长后再考虑 MILP、分支定界或启发式。
- 最近邻可做快速 baseline，但不提供通用最优保证；最终必须独立重算 tour 长度并检查每节点恰访问一次。
- 使用启发式时与同预算 baseline 比较，并在可解的小实例上校准 gap。

## Chinese Postman / Route Inspection

- 与 TSP 区分：邮差问题要求覆盖边，TSP 通常要求访问节点。
- 无向图先检查连通性与奇度节点；需要重复边时基于最短路配对/扩充，并独立核对所有必需边均被覆盖。
- 有向或混合图需使用相应版本，不能直接套无向结论。

## Common validation

检查边合法性、方向、权重单位、可达性、访问/覆盖约束，并独立累加 objective。动态场景另查未来信息泄漏。
