# Fuzzy Comprehensive Evaluation

适用于指标具有“差/一般/良/优”等模糊等级、且需要把连续/定性指标映射到等级隶属度的评价问题。若任务只是普通确定性排序，优先用更简单的多指标评价 baseline。

1. 定义因素集 `U={u_i}` 与评价等级集 `V={v_j}`，每个等级必须有业务/题意含义。
2. 对每个指标建立隶属函数，说明阈值/形状来源；不要仅为了得到平滑结果任意画三角函数。
3. 形成隶属度矩阵 `R`，逐行检查非负与和为 1（在采用概率式归一定义时）。
4. 权重 `w` 的来源与 `multi-criteria-evaluation` 一致：主观/客观/混合均需说明含义并做敏感性。
5. 综合运算 `B = w^T R` 或其他算子必须明确；最大隶属度原则与加权等级得分会产生不同信息损失，应按任务选择。
6. 与等权/确定性 baseline 对照，并扰动隶属函数和权重，检查等级是否脆弱翻转。
7. 输出时解释“隶属度/综合等级”，不得写成未经定义的真实概率。
