# Evolutionary Game Playbook

演化博弈用于大群体中策略比例随复制、学习、模仿或选择压力演化的问题。它与一次性 Nash/Stackelberg 不同：核心对象是 population state 与其动力学。

## 1. 适用结构

- 玩家数量大或可视作连续群体。
- 个体使用有限策略集合，收益依赖当前群体策略分布。
- 问题关心长期策略占比、侵入稳定性、政策诱导或行为演化。

若玩家是少数明确决策主体且追求静态最优反应，优先普通 game-theory。

## 2. 基本合同

1. 定义策略集合与群体比例 `x_i`，满足非负和总和为 1。
2. 写收益 `pi_i(x, theta)` 与平均收益；收益依据必须来自机制/数据/显式假设。
3. 选择演化机制。经典 replicator dynamics 适合收益比例驱动的无突变模仿；若有突变、有限群体、网络结构或异质学习，应明确扩展机制。
4. 求固定点并检查局部稳定性；固定点不自动等于 ESS，需按定义/扰动条件验证。
5. 对初始策略比例和关键收益参数做情景分析，识别多吸引域和路径依赖。

## 3. 验证

- 单纯形不变性：比例不能变负，总和保持 1。
- 数值积分与解析平衡点/二维相图（适用时）交叉检查。
- 多初值验证 basin of attraction，不用一条轨迹宣称唯一长期状态。
- 对收益矩阵微扰检查 ESS / 稳定点是否翻转。
- 若有历史策略占比，比较趋势/稳态而非逐点过拟合。

## 4. 常见误用

- 为了“动态”把静态 Nash 加一条随意微分方程。
- 把稳定固定点、Nash equilibrium、ESS 三个概念混为一谈。
- 收益函数完全由作者设定却写成行为事实。
- 用平均场 replicator 解释强网络局部互动而不检查网络效应。

## 5. 与其他 Skill 组合

- 政策制定者与群体主从互动：`game-theory` + Stackelberg，再对群体层用演化动态。
- 连续动力学数值稳定性：组合 `ode-dynamics`。
- 个体异质、网络局部学习不可忽略：考虑 `agent-based-modeling`。

论文至少报告策略、收益、演化方程、固定点/稳定性、初值与参数敏感性，以及均衡概念的精确定义。
