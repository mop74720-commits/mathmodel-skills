# Citation & Evidence Planning Before Drafting

A citation plan is a lightweight bridge between outline, verified sources and the Claim-Evidence Map. It prevents post-hoc citation stuffing.

## Claim roles

Classify each statement that needs support:

- `PROBLEM_FACT`: comes from the official problem/data;
- `METHOD_JUSTIFICATION`: why a method/assumption is defensible;
- `DEFINITION_OR_THEORY`: established concept/equation/property;
- `COMPARATIVE_BACKGROUND`: known alternatives or prior results;
- `LOCAL_RESULT`: produced by this competition run;
- `INTERPRETATION`: explanation bounded by local evidence;
- `LIMITATION`: known scope/failure condition.

## Source plan

For external citations record:

- claim/section;
- citation purpose;
- verified source identifier (DOI/official URL/bibliographic key);
- exact point the source supports;
- source quality/status;
- whether primary source is required;
- any mismatch or caveat.

Do not cite a survey as proof of a theorem when the primary source is readily available. Do not use literature to “prove” a numerical result generated by the local model.

## Writing order

1. Freeze a provisional outline and main claims.
2. Build the source plan for method/theory/background claims.
3. Build the local evidence map for run/table/figure claims.
4. Draft only claims whose evidence path is known, or mark an explicit evidence gap.
5. After drafting, verify that each citation supports the exact sentence rather than merely sharing keywords.

## Rigor level

Competition writing normally uses targeted evidence search. Narrative/scoping/systematic-review protocols are loaded only when the task actually requires that level of literature rigor.
