# Overlap Quality Selection — v0.1.6

本矩阵只比较“当前 Hub 与 Han/XiaoMa 同时拥有的能力”。原则不是来源优先，而是按同一能力的实际质量择优：触发边界、方法完整性、防错、可验证性、比赛可用性、复现性、维护成本和许可风险。

## 明确不选的内容

- 不恢复 Han 的固定 12 阶段链和 Legacy 重复入口。
- 不采用“数据量小于某阈值就固定选 GM(1,1)”一类过硬模型选择捷径。
- 不采用主观 Innovation Score / paper-score 作为科学或官方结论。
- 不把“必须 N 张图 / 固定 N 页 / 固定字数”作为通用硬门槛；只有当届官方规则可成为硬约束。
- 不把“Y 轴必须从 0 开始”“一律 600 dpi”等情形规则写成普遍真理。
- 不复制 XiaoMa 中带限制性许可的 DOCX/PDF 源码、模板或其衍生代码；只依据公开可观察能力边界独立实现。

## 选择标准

同一能力按以下优先级裁决：

1. 能否减少错误结论，而不只是增加步骤；
2. 是否有清晰输入、输出、失败和 handoff；
3. 是否能机械复现或被独立验证；
4. 是否避免把经验规则冒充官方规则/数学真理；
5. 是否适合原子 Skill，而不是重新形成第二个总管；
6. 许可和再分发边界是否清晰。
